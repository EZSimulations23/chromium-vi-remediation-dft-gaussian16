# Chromium(VI) Remediation — Gaussian-16 Computational Data

Computational data and supporting analyses for the research article:

**“Remediation of hexavalent chromium in groundwater: Kinetic and DFT study of the termolecular transition state involving monochromate, oxalic acid and ethanol.”**

This repository contains Gaussian 16 computational files and associated analyses supporting the density functional theory (DFT) investigation of the reaction mechanism and transition state proposed in the article.

## Contents

- **Optimized structures:** Computational structures and associated Gaussian output files.
- **Transition-state validation (TTS):** Transition-state calculations and Intrinsic Reaction Coordinate (IRC) analyses used to investigate the connection between the transition state and the corresponding reaction pathway.
- **Potential Energy Surface (PES):** Gaussian input and output files supporting the PES calculations.
- **Relative Energy Diagrams (RED):** Energy analysis spreadsheets and associated figures.
- **Computational outputs:** Gaussian input (`.gjf`), checkpoint (`.chk`), formatted checkpoint (`.fchk`), and log (`.log`) files, where available.
